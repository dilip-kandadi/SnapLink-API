# 💰 Expense Tracker Web Application

A lightweight, responsive, and user-friendly Expense Tracker built using vanilla web technologies. This application allows users to effortlessly monitor their personal finances, track daily spending, and maintain a historical record of transactions without requiring a backend database.

## ✨ Key Features

* **Dynamic Transaction Management:** Add and delete income or expense items instantly with real-time UI updates.
* **Persistent Data Storage:** Utilizes the browser's native **Local Storage API** (`JSON.stringify` & `JSON.parse`) to ensure user data remains intact across browser refreshes and sessions.
* **Instant Balance Calculation:** Automatically computes and updates total balance, total income, and total expenses on the fly using JavaScript array methods.
* **Responsive & Modern UI:** Designed with clean CSS Flexbox layouts for optimal readability and seamless navigation across desktop and mobile screens.
* **DOM Manipulation:** Fast and efficient rendering of transaction lists using modern JavaScript DOM event listeners and template literals.

---

## 🛠️ Tech Stack

* **Frontend Structure:** HTML5 (Semantic elements, accessibility best practices)
* **Styling & Layout:** CSS3 (Flexbox, custom styling, responsive design)
* **Logic & State Management:** Vanilla JavaScript (ES6+, DOM Manipulation, Event Handling)
* **Client-Side Storage:** Browser Web Storage API (LocalStorage)
